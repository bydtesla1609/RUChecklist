LET’S GET CONNECTED

连接你的作业网站

首次在电脑 Edge 中完成下面 4 步。之后登录同一个账号，手机也能看到同步的任务。

1安装同步扩展只需安装一次
  1. 下载扩展安装包，在电脑上右键选择“全部解压缩”。
  2. 复制 edge://extensions 到 Edge 地址栏打开。
  3. 打开“开发人员模式”，点“加载解压缩的扩展”，选择解压后的 extension 文件夹。
  4. 回到这个网页，点击下方按钮。更新扩展时，在管理页点一次“重新加载”。

2连接当前账号

正在检查扩展…

不用复制配对码。换账号或换看板时，请重新连接。

3粘贴你的作业页面链接

先在 Edge 登录你的作业网站，进入“作业”列表，把地址栏中的完整链接复制粘贴到这里。多个页面每行一个。

哪些网站可以自动导入？

目前已适配 SmartEstu、课堂派、学习通，以及人大教务课表 / 考试。你可以填写自己使用的页面，不需要与示例账号相同。其他网站可保存为入口，暂时需要手动添加任务；添加链接不代表已完成适配。

4完成首次同步

点击后，扩展会打开你保存的页面。若出现登录页，请在对应网站完成登录，再回来同步。

正在检查同步状态…

教务导入使用电脑 Edge 中已登录的课表、考试查询页。

出现“已同步”和接收数量后，就可以关闭本窗口。普通浏览器采集在电脑休眠 / 关机时暂停；已同步的任务仍可在手机访问。
